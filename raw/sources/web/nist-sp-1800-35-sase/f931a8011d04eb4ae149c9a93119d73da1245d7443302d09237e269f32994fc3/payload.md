# NIST SP 1800-35 — what SASE converges

- Source: https://nvlpubs.nist.gov/nistpubs/SpecialPublications/NIST.SP.1800-35.pdf
- Publication: NIST Special Publication 1800-35, *Implementing a Zero Trust Architecture*
- Retrieved: 2026-09-13
- Extracted for: whether virtual desktop infrastructure is part of what SASE converges.

## Definition as published

> SASE delivers converged network and security as a service capability, including
> Software-Defined Wide Area Network (SD-WAN), Secure Web Gateway (SWG), Cloud Access
> Security Broker (CASB), Next Generation Firewall (NGFW) and Zero Trust Network Access
> (ZTNA). SASE supports branch office, remote worker, and on-premises secure access use
> cases. SASE is primarily delivered as a service and enables zero trust access based on
> the identity of the device or entity, combined with real-time context and security and
> compliance policies.

## Observation

The enumerated capabilities are SD-WAN, SWG, CASB, NGFW and ZTNA. Virtual desktop
infrastructure does not appear in that list, and the document treats SASE as one of the
implementation approaches alongside software-defined perimeter and microsegmentation.
